## What it is

`main.ts` (Node 22, standard library only, no network) writes a single word to `entry.txt`:

- **The word**: `contraption` — the word a grandmother reaches for when a machine is too clever and too complicated to name properly. Warm and a little baffled, funny in one word, tied to the machine itself, and instantly readable.

The program writes exactly that word — eleven characters, no trailing newline, no extra whitespace — to the output file the grader reads.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

This writes `out/entry.txt` containing `contraption` (11 bytes).
